# Encoded Radiance Studio Favicon Package

## Repository location

Copy all files into:

`public/assets/images/brand/`

## Add to every HTML file

Place the contents of `favicon-head-snippet.html` inside each page's `<head>` element.

Recommended pages:

- `public/index.html`
- `public/about.html`
- `public/er.html`
- `public/links.html`
- `public/press.html`
- `public/live-listen-radio.html`
- `public/license.html`

## Main website brand image

For visible page branding, use:

```html
<img
  src="/assets/images/brand/primary/encoded-radiance-primary-responsive.svg"
  alt="Encoded Radiance Studio"
  class="site-brand-image"
>
```

Use the actual path that matches where the approved SVG size package is copied.
